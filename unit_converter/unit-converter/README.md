# 📏 Hooria's Unit Converter

Welcome to **Hooria's Unit Converter** — a simple and beginner-friendly app made with Python and Streamlit to convert basic metric units like meters, kilometers, grams, and kilograms. 🚀

---

## 🧠 About the Project

This project helps you:

✅ Convert between **meters ↔ kilometers**  
✅ Convert between **grams ↔ kilograms**  
✅ Enjoy a clean and responsive web interface  
✅ Learn how **functions**, **UI**, and **logic** work together in Python

Built with 💖 using:

- **Python**: Powerful & beginner-friendly programming language  
- **Streamlit**: A Python library to quickly build data/web apps
